## What this is

A meal-planning web app (Next.js 15 App Router, React 19, SQLite via
Drizzle) for Calvin's homelab, paired with `dionysus-service` (Scala 3 +
Pekko, the meal/batch inventory, pinned v0.1.0) and `dionysus-ios`
(SwiftUI companion). Deployed to k3s on the QNAP NAS (`mimir`) at
`dionysus.lan:61642` (LAN) / `mimir.tail783b49.ts.net:61642` (tailnet).
NO AUTH anywhere — private networks only, never expose publicly.

## The process (non-negotiable)

Every change: OpenSpec change dir (`openspec/changes/<name>/` —
proposal, tasks, delta specs) → implement → full gate (lint, tsc,
`vitest run`, `playwright test --workers=1` all projects, service-gated
specs against a local `calvinference/dionysus:dev` container on :18080)
→ sync delta specs into `openspec/specs/`, archive the change → branch →
gated PR (5 CI jobs; `checks`/`e2e`/`docker-smoke` are required) → merge
(verify state == MERGED before tagging — never pipe gating commands) →
tag vX.Y.Z (Release workflow builds the image AND creates the GitHub
release — never `gh release create` manually; never reuse a tag) → helm
upgrade `--reuse-values --set image.tag=X.Y.Z` (remote: add
`--kube-apiserver=https://100.107.133.54:6443
--kube-tls-server-name=mimir`; never skip TLS verify) → verify live.

## Architecture map

- `domain/` — pure, framework-free logic (units, nutrition, planner
  math, cooklang parser, category tree/defaults, list sort, backup
  markdown, dashboard stats). Unit-tested; keep it pure.
- `data/` — the only layer touching drizzle/better-sqlite3.
  `repositories/*` are dumb queries; `data/*.ts` facades open/close a
  DB per call. Migrations in `drizzle/` (0003–0019), applied at boot.
- `app/actions/` — server actions; validation via shared zod schemas in
  `domain/validation/` (ADR-005: parse on both sides).
- `app/api/` — route handlers. `/api/mobile/*` is the iOS surface;
  document every route in `lib/openapi.ts` (an integration test
  enforces this, by importing each route module — see the drift gate).
- `services/dionysusService.ts` — the ONLY client for the Scala
  service. Cook/eat flows are service-first, all-or-nothing.
- UI: dark-only cyberpunk theme; `tests/unit/uxStandards.test.ts` pins
  the tokens to `codex/docs/ux-standards.md` (dionysus is the reference
  implementation). No hardcoded colors in components.

## Load-bearing invariants

- `resolveQuantityForComparison` (domain/units) is the single
  unit/package/density choke point — no parallel conversion paths.
- Generic/product interchange: recipes reference generics or products;
  matching merges rows per generic root (`domain/interchange.ts`).
- Derived recipe tags are COMPUTED at read time from ingredient
  categories (never written to `recipe_tag`); category paths nest with
  "/" and expand per level.
- Variations are full recipes with `variantOfId` → the ROOT (never
  nested chains).
- Plan entry kinds: cook, eat_batch, eat_item (already eaten),
  eat_pantry (planned pantry item). Immediate consumption (Eat/Drink
  now, cook eaten-now, Log-1) always records an eat_item on today.
  Planning RESERVES (visible planned counts), never consumes; the
  entry's Eat/Drink button logs on the ENTRY's date and sets
  consumedAt (consumed entries stop reserving, lose their buttons).
- Batches merge one-row-per-recipe in UIs; logging targets the OLDEST
  batch (FIFO). Per-batch truth lives on the Batches admin page.
- ABV entry renders only for DRINK+VOLUME (stored as g/100mL via
  ethanol density 0.789); CRDM unit = (mL × ABV%)/17.
- Logging: `lib/logger.ts` emits JSON lines ({ts, level, event, ...}).
  Routes wrap their body in `withRouteLog` (keeping the
  any export shape — the drift gate imports the module, not the text);
  `dionysusService#request` is the ONE outbound log point. Level via
  DIONYSUS_LOG_LEVEL, silent under NODE_ENV=test. Never log bodies.
- `formatQuantity` (domain/quantityFormat) is the DISPLAY rounding
  boundary — at most 2 decimals, trailing zeros dropped. Never feed its
  output back into arithmetic; nutrition keeps formatNutritionForDisplay.
- Pack units: `{1%pack}` mentions expand through ingredient.packQuantity
  at line-building time (display verbatim); matching degrades unknown
  display units to the class canonical unit. Ladder: each → pack →
  package → 100 g/mL.
- e2e specs use run-unique names, delta-based assertions, and nest new
  `it` blocks inside the fixture describe. Playwright serves the last
  `next build` — always build before local e2e.

## API + docs

`/api-docs` renders `lib/openapi.ts` (house-style viewer);
`/api/openapi` serves the JSON; `/insomnia-collection.json` is
generated by `scripts/generate-insomnia.mjs`. Backup: `/api/backup`
(lossless JSON) + `/api/backup/markdown`;
`scripts/backup-to-obsidian.sh` syncs `~/Mindmap/Dionysus`.
